# Roteiro de estudo

Marque cada etapa ao concluir. Em cada uma: conceito, código feito junto e um exercício sozinho.

- [ ] **1. Fundação** — ambiente Python, estrutura do projeto, primeira chamada à API do Claude;
      tokens, janela de contexto, temperatura, system prompt.
- [ ] **2. MVP sem IA** — cadastro de produtos, upload, prazo de garantia, busca simples (SQLite).
- [ ] **3. Extração da nota fiscal** — LLM com visão, saída estruturada (JSON validado), tratamento de erro.
- [ ] **4. Embeddings e busca semântica** — o que é um embedding, similaridade, busca por significado.
- [ ] **5. RAG em manuais e termos de garantia** — chunking, banco vetorial (Chroma), respostas com fonte.
- [ ] **6. Agente de garantia** — tool use: consultar produtos, calcular prazo, montar alerta de vencimento.
- [ ] **7. Avaliação** — conjunto de testes, medir acerto, custo e latência, melhorar.
- [ ] **8. Extras** — interface web, notificações, servidor MCP próprio.
